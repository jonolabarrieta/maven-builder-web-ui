# Optimización de carga — 16 de octubre de 2026

## Cambios

- Sustituido Tailwind Play CDN por CSS estático minificado generado con Tailwind 3.4.17. El navegador deja de descargar y ejecutar el compilador de estilos.
- Integrados los estilos de color y responsive en `static/css/app.css`.
- HTMX 1.9.10, SockJS 1.6.1, STOMP 2.3.3 y Sortable 1.15.6 se sirven desde el JAR, con versiones fijas, archivos de licencia y archivos npm comprobados con SHA-512.
- Todos los scripts con `src` usan `defer`. La conexión WebSocket se inicia después de cargar sus dependencias.
- Activada la compresión HTTP de HTML, CSS, JavaScript y JSON a partir de 1 kB.
- Añadidos comandos de generación/restauración, documentación y comprobación de CSS actualizado en CI. El empaquetado Maven utiliza los recursos incluidos y no requiere Node.js.

La referencia anterior es el runtime oficial de Tailwind Play CDN 3.4.17, descargado antes de la sustitución; el nuevo CSS incluye también los estilos propios de color y responsive.

Comprobación HTTP real contra Tomcat local, solicitando `Accept-Encoding: gzip`:

| Recurso | Original | Transferencia gzip |

Ambas respuestas incluyen `Content-Encoding: gzip`; al descomprimir coinciden byte a byte con los archivos originales. La diferencia respecto al gzip local se debe al compresor utilizado por el servidor.
